# Ahmed Alharthy - Portfolio

Personal portfolio site, hosted free on GitHub Pages.

## How to publish (about 10 minutes)
1. Sign in to github.com. Click **New repository**.
2. Name it exactly `Ahmed-018.github.io`. Set it to **Public**. Click **Create repository**.
3. Click **uploading an existing file**, then drag in everything inside this folder (the .html files, README.md and the `assets` folder). Click **Commit changes**.
4. Go to **Settings > Pages**. Under "Build and deployment", choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
5. Wait 1-2 minutes and open `https://ahmed-018.github.io`.

## Updating
- New CV: replace `assets/Ahmed_Alharthy_CV.pdf` with a file of the same name.
- New project: copy `solar-vehicle.html`, rename it, change the text and images, and add a row to the Projects list in `index.html`.
